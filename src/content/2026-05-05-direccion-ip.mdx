# Qué es una dirección IP y por qué es tan importante

> 'IP' significa 'Internet Protocol' o 'Protocolo de Internet', que es un conjunto de reglas que rigen cómo los dispositivos se comunican a través de Internet. 

Cada dispositivo conectado a Internet tiene una dirección IP única, que es como su dirección postal en el mundo digital. Esta dirección permite 
que los datos se envíen y reciban correctamente entre dispositivos. Si hacemos una analogía, la dirección IP es como la dirección de tu casa: si pedís una
pizza, el deliver necesita tu dirección para saber dónde entregarla. 

![IP](/images/ip.svg)

Para leer este blog, necesitas solicitarle al servidor que tiene el contenido que te lo envíe. Para eso, tu computadora envía una solicitud al 
servidor quien cuando la reciba también necesita saber a donde enviar la respuesta. Por eso, la solicitud incluye la dirección IP del solicitante,
en este caso la tuya. El servidor recibe la solicitud, procesa la información y luego envía la respuesta de vuelta a tu dirección IP para que puedas
ver el contenido del blog.

El sistema que orquesta esto es llamado DNS (Domain Name System). Es como una guía telefónica: cuando escribís "www.google.com" en tu navegador, 
el DNS traduce ese nombre de dominio a la dirección IP correspondiente para que tu computadora pueda conectarse al servidor correcto y mostrarte el sitio web.

# Diferencia entre IPv4 e IPv6

No entraré en detalles técnicos, pero es importante mencionar que existen dos versiones principales de direcciones IP: IPv4 e IPv6.

- **IPv4**: Es la versión más antigua y utiliza direcciones de 32 bits, lo que permite aproximadamente 4.3 mil millones de direcciones únicas (ejemplo: `192.2.0.1`). Con el crecimiento exponencial de dispositivos conectados a Internet, 
se agotaron las direcciones IPv4 disponibles y se introdujo IPv6.
- **IPv6**: Es la versión más reciente y utiliza direcciones de 128 bits, lo que permite una cantidad prácticamente ilimitada de direcciones únicas (ejemplo: `2001:0db8:85a3:0000:0000:8a2e:0370:7334`). IPv6 también incluye mejoras en la eficiencia 
y seguridad de las comunicaciones en Internet.

# Diferencia entre IPs estáticas y dinámicas

- **IP estática**: Es una dirección IP fija que no cambia. Es como tener una dirección de casa permanente. Las IPs estáticas son útiles para servidores, 
dispositivos de red y cualquier dispositivo que necesite ser accesible de manera constante. (por ejemplo, Cloudfare's 1.1.1.1)
- **IP dinámica**: Es una dirección IP que puede cambiar cada vez que te conectas a Internet. Es como alquilar una casa: cada vez que te mudas, obtienes una nueva dirección. 

La idea de Ip dinámica surge de la limitación de direcciones IPv4, ya que con el crecimiento de Internet, se necesitaba una forma de reutilizar 
las direcciones IP disponibles. Por ejemplo, desde casa me conecto a mi Internet y mi proveedor (ISP) me asigna una IP temporal dentro de un rango de
direcciones que tiene disponibles. Cuando me desconecto, esa IP vuelve a estar disponible para que otro usuario la use.
Esto permite que más personas puedan conectarse a Internet sin agotar las direcciones IPv4 disponibles.
