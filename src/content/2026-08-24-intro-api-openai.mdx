# La API de openAI

Supongo que si estas leyendo esto sabes que es una API pero nunca esta de más recordar una pequeña definición:

> Una API (Application Program Interface) es un contrato que permite que dos aplicaciones se comuniquen entre sí. En otras palabras, 
es un conjunto de reglas y protocolos que permiten que diferentes programas interactúen y compartan datos de manera eficiente.

En este contexto, la API de openAI permita aplicar la IA a casi cualquier tarea que implique entender o generar lenguaje natural, código o imágenes. El diseño
del prompt es como "guías" la respuesta del modelo, proporcionando algunas instrucciones o ejemplos. El número de tokens procesados en una solicitud
de API determinada depende de la longitud tanto de sus entradas como de tus salidas.

> Regla: 1 token ~= 4 caracteres en inglés, o 1 palabra en promedio. El prompt + la respuesta no pueden superar la longitud del contexto máximo del modelo.

# Endpoint `/completions` LEGACY, ahora `/responses`

Viendo la teoría del curso que realice, encuentro que se habla del endpoint `/completions` como el endpoint principal para generar texto, 
pero en la documentación actual de OpenAI, se menciona que este endpoint ha sido reemplazado por `/responses`, el cual proporciona una interfaz completa del sistema de IA.

No entrare tanto en detalle sino que me interesa que veamos conceptos relacionados a los parámetros de generación. En caso que te interese, te dejo [este link]("https://dev.to/dev-in-progress/chat-completions-vs-openai-responses-api-what-actually-changed-4bco")
donde compara ambos endpoints. Más adelante veremos ejercicios prácticos de como usar la API de OpenAI y otras.

# Parámetros de generación

Cuando llamamos al modelo, le pasamos parámetros que cambian cómo genera la respuesta.

## `temperature` - ¿determinista o creativo?

`temperature` (0 a 2) controla la aleatoriedad:
- 0: el modelo elige siempre el token más probable, las respuestas son mas estables y repetibles.
- Alto (1-1.5): más variedad y creatividad pero menos predecible.
